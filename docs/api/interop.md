# Interoperability

`fdatools.interop`: lossless bridges to NumPy, SciPy (`scipy.interpolate.BSpline`)
and scikit-fda; `(entity, time)` panels for linearmodels and statsmodels; and
design matrices that let any linear estimator (OLS, WLS, GLM, quantile
regression, IV, panel fixed effects) fit a scalar-on-function model. See the
[econometrics tutorial](../tutorials/econometrics.md).

::: fdatools.interop
